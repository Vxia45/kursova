# Студентски форум за курсови работи - Docker Compose Контейнеризация

Този проект представлява просто уеб приложение (Студентски форум) за споделяне на въпроси и намиране на съотборници за курсови работи. Проектът е изграден на PHP и MySQL и е напълно контейнеризиран чрез Docker и Docker Compose.

---

## 📂 Структура на проекта

```text
kursova/
├── db_init/
│   └── init.sql          # SQL скрипт за първоначално създаване на таблиците и демо данни
├── src/
│   ├── db.php            # Настройка на връзката с базата данни (с поддръжка на Docker и XAMPP)
│   └── index.php         # Основен код и интерфейс на приложението
├── styles/
│   └── style.css         # Стилизация на приложението
├── .dockerignore         # Списък с файлове, които да не се включват в Docker образа
├── .gitignore            # Списък с файлове, които да се игнорират от Git
├── compose.yml           # Дефиниция на Docker Compose услугите
├── Dockerfile            # Конфигурация за изграждане на PHP/Apache контейнера
└── README.md             # Документация на проекта (този файл)
```

## ⚙️ Как работи всеки от компонентите

1. **Бекенд и Уеб Сървър (`web` контейнер):**
   - Използва официален Docker образ `php:8.2-apache`.
   - Инсталира се разширението `pdo_mysql` за връзка с MySQL.
   - Активира се модулът `mod_rewrite` на Apache.
   - Домакинства PHP файловете от директория `src` и стиловете от `styles`.
   
2. **База данни (`db` контейнер):**
   - Използва Docker образ `mysql:8.0`.
   - Автоматично инициализира базата данни `kursova` при първото стартиране, като изпълнява скрипта `db_init/init.sql`.
   - Запазва данните трайно чрез Docker Volume (`mysql_data`), така че данните да не се губят при рестартиране или изтриване на контейнерите.

## 📡 Комуникация между услугите

Комуникацията се осъществява чрез вградената виртуална мрежа на Docker Compose:
- Двете услуги (`web` и `db`) се намират в една и съща мрежа по подразбиране, създадена от Docker Compose.
- Бекенд кодът в `src/db.php` се свързва с базата данни, използвайки името на услугата `db` като хост (вместо `localhost`).
- В `src/db.php` се четат променливите на средата (`DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`), подадени от `compose.yml`. Ако тези променливи не са зададени, проектът автоматично се връща към настройки по подразбиране за XAMPP (`localhost`, потребител `root` и парола `1234`), което запазва пълна съвместимост.
- Услугата `web` има дефинирана зависимост `depends_on` с проверка `service_healthy`. Това гарантира, че уеб сървърът ще се стартира чак след като базата данни MySQL е напълно готова да приема връзки.

## 🚀 Как се изграждат и стартират контейнерите

### 1. Стартиране на приложението
За да стартирате проекта локално чрез Docker Compose, отворете терминал в главната директория на проекта и изпълнете:

```bash
docker compose up -d --build
```

- Флагът `-d` стартира контейнерите в фонов режим (detached mode).
- Флагът `--build` гарантира, че Docker образът за уеб сървъра ще бъде изграден наново.

След успешно стартиране приложението ще бъде достъпно на адрес:
👉 **[http://localhost:8080/src/index.php](http://localhost:8080/src/index.php)**

Базата данни ще бъде достъпна на порт `3306` на вашия хост.

### 2. Спиране на контейнерите
За да спрете услугите и да премахнете контейнерите, изпълнете:

```bash
docker compose down
```

Ако искате да изтриете и запазените данни в базата данни (напълно изчистване на обема):
```bash
docker compose down -v
```

## 🐳 Публикуване на Docker образи в Docker Hub

За да качите уеб сървър образа в Docker Hub, изпълнете следните стъпки:

1. **Впишете се във вашия Docker Hub профил през терминала:**
   ```bash
   docker login
   ```
   *(Въведете потребителското си име и парола/токен)*

2. **Изградете и тагнете образа на проекта:**
   Заменете `<your-dockerhub-username>` с вашето потребителско име в Docker Hub.
   ```bash
   docker build -t <your-dockerhub-username>/kursova-web:latest .
   ```

3. **Качете образа в Docker Hub:**
   ```bash
   docker push <your-dockerhub-username>/kursova-web:latest
   ```

## 🐙 Качване на проекта в GitHub

За да качите кода и Docker конфигурациите в GitHub, изпълнете:

1. **Инициализирайте Git хранилище локално (ако не е направено):**
   ```bash
   git init
   ```

2. **Добавете файловете и направете първия комит:**
   ```bash
   git add .
   git commit -m "Initial commit: Add application code and Docker Compose configuration"
   ```

3. **Създайте публично хранилище в GitHub и го свържете:**
   ```bash
   git remote add origin https://github.com/<your-github-username>/<your-repo-name>.git
   git branch -M main
   ```

4. **Изтласкайте промените:**
   ```bash
   git push -u origin main
   ```
