# Курсова работа: Контейнеризация на проект "Студентски форум"

Този проект демонстрира пълна контейнеризация на уеб приложение ("Студентски форум"), реализирано на PHP, което комуникира с MySQL база данни за съхранение на дискусионните теми. Цялата среда е конфигурирана и се управлява автоматично чрез **Docker** и **Docker Compose**.

---

## Структура на проекта

Проектът е организиран в следния вид:
* `src/` — съдържа сорс кода на PHP приложението (`index.php`, `db.php`).
* `styles/` — съдържа стиловите CSS файлове за уеб интерфейса.
* `db_init/` — съдържа SQL скрипт за автоматична първоначална настройка.
* `Dockerfile` — инструкции за изграждане на персонализирания уеб сървър.
* `compose.yml` — дефиниция и мрежова свързаност на контейнерите.
* `kursova.sql` — базов SQL скрипт за инициализация на базата данни.

---

## Архитектура и компоненти

Проектът се състои от две основни услуги, работещи в изолирана среда:

### 1. Уеб сървър (`web`)
* **Базов образ:** `php:8.2-apache`
* **Фини настройки (Dockerfile):** Инсталирано е разширението `pdo_mysql`, необходимо за връзката с базата данни.
* **Порт:** Конфигуриран е да слуша на порт `8080` (мапнат като `8080:80`).
* **Качен образ:** Персонализираният образ е публично достъпен в Docker Hub: [vxia/kursova-web](https://hub.docker.com/r/vxia/kursova-web)

### 2. База данни (`db`)
* **Базов образ:** `mysql:8.0`
* **Персонализация:** Използва се изолиран Docker обем (`mysql_data`), за да се гарантира персистентност (запазване) на данните, дори след спиране или изтриване на контейнерите.

---

## Мрежова комуникация между услугите

Услугите комуникират помежду си чрез автоматично създадената вътрешна мрежа от Docker Compose.

Във файла `src/db.php`, за връзка се използват променливите на средата, като хостът е името на Docker услугата:
```php
$host = "db";
```
Docker автоматично разпознава това име и пренасочва уеб трафика от PHP контейнера към MySQL контейнера.

---

## Инструкции за стартиране

За да изградите и стартирате проекта локално на вашия компютър, следвайте тези стъпки:

1. Свалете проекта и отворете терминала в неговата директория.
2. Стартирайте контейнерите на заден план (Detached mode) чрез Docker Compose:
   ```bash
   docker compose up -d
   ```
3. Ако искате да импортирате базата данни ръчно от локалния `kursova.sql` файл в Docker контейнера, можете да го направите със следната команда (въпреки че базата данни се инициализира автоматично чрез скрипта в `db_init/` при първо стартиране):
   ```bash
   docker exec -i kursova-db-1 mysql -u root -proot_password_1234 kursova < kursova.sql
   ```
4. Отворете вашия браузър и достъпете приложението на адрес:
   ```text
   http://localhost:8080/src/index.php
   ```

---

## Спиране на средата

Когато приключите работа и искате да освободите системни ресурси, можете да спрете и премахнете контейнерите с командата:
```bash
docker compose down
```
